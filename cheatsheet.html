Results in one line each

  • Obliqueness. θ up → amplitude down, width up. Peak |U| = 1.85, 1.17, 0.65 at θ = 10°, 20°, 30° (Fig. 6).
  • Fractional order. β rescales horizontally; amplitude unchanged, because β lives only inside ξ and never reaches B₁ (Fig. 9).
  • Branch. χ < 0 → cosh/sinh, a kink bounded by |B₁|√−χ. χ > 0 → cos/sin, periodic. Both bounded for real ξ.
  • Plateau. |B₁|√−χ = 2.267, 1.948, 1.500 at θ = 10°, 30°, 50° — matches Fig. 5's 2.28, 1.96, 1.51.
  • Time. Rigid translation of the profile — the definition of a travelling wave (Fig. 11).

Five sentences you should be able to say cold

  1. The opening

    "I derived exact travelling-wave solutions of the (2+1)-dimensional nonlinear hyperbolic Schrödinger equation under a beta fractional derivative, using the Unified Technique."

  2. Why hyperbolic

    "The two second derivatives enter with opposite signs, so the linear operator is the wave operator rather than the Laplacian."

  3. Why N = 1

    "Balancing u″ against u³: each derivative raises the power of δ by one, so N + 2 = 3N."

  4. Why β vanishes

    "The transformation is built so the beta derivative of ξ is exactly l — the exponents cancel — so β never appears in the reduced ODE."

  5. The bridge to numerics

    "My project was analytical, not numerical. Exact solutions are what you validate solvers against, and I've since implemented mine in Python, reproduced my figures, and found and corrected an error in the published constants doing it."

Before the call

Do

  • Open the lab and run Cell 1 so Pyodide is already loaded.
  • Have the report open at the derivation, Chapter 3.
  • Have paper and pen — ask to write when the question is algebraic.
  • Name the ω correction yourself if verification comes up at all.
  • Give numbers, not adjectives.

Don't

  • Call them solitons without qualification — say solitary or exact travelling-wave.
  • Claim the Unified Technique as your own contribution.
  • Claim integrability because you found exact solutions.
  • Describe the project as numerical.
  • Bluff a language or method you have not used.
