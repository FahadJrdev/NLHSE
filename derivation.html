1 · The fractional travelling-wave transformation

U(x, y, t) = eiφ u(ξ) ξ = (l/β)(x + 1/√β)β + (m/β)(y + 1/√β)β − (ω/β)(t + 1/√β)β φ = −(l/β)(x + 1/√β)β − (m/β)(y + 1/√β)β + (c/β)(t + 1/√β)β
(12)

with l = cos θ and m = sin θ, so that l² + m² = 1 and θ is the oblique angle.

Why the transformation has this exact shape

Because the beta derivative is (x + 1/Γ(β))1−β · d/dx, applying it to (1/β)(x + 1/Γ(β))β gives (x + 1/Γ(β))1−β · (x + 1/Γ(β))β−1 = 1. The exponents cancel exactly. So ᴬ₀𝔇βxξ = l, exactly as ∂ξ/∂x = l would be in the classical case. The transformation is constructed precisely so that the fractional derivative disappears. That is the answer to "why does the β go away?" and it is the single best thing to be able to say about this derivation.

The inconsistency, stated once

The report writes 1/√β here, while Eq. (3) defines the operator with 1/Γ(β). The cancellation above only works with the Γ(β) form. See page 03 for how to answer this.

2 · The converted ODE

Substituting (12) into (1) collapses the PDE to:

i u′(m − l² + cω²) + ½ u″(l² − ω²) + uζ + u³ = 0
(13)

where the constant ζ gathers everything the parameters contribute:

ζ = { m − ½l² − ½ ( (l⁴ − 2l²m + m²) / ω² ) }

Three variables have become one. Note what survives: β does not appear in (13) at all. The fractional order is entirely inside the definition of ξ. This is the fact that makes the whole approach tractable, and it is worth pointing at explicitly.

3 · Separating real and imaginary parts

u(ξ) is real, so (13) can only hold if its real and imaginary parts vanish separately. That single observation splits one complex equation into two real ones:

Real: ½ u″(l² − ω²) + uζ + u³ = 0
(14)
Imaginary: i u′(m − l² + cω²) = 0
(15)

4 · The speed falls straight out

u′ is not identically zero — a constant solution would be trivial — so the bracket in (15) must vanish. That is one linear equation for c:

m − l² + cω² = 0 ⟹ c = (l² − m)/ω
(16)

A free win, and examiners like it

The phase speed is not a free parameter. It is forced by the requirement that a real profile solve a complex equation. No solving needed — the imaginary part is linear and hands it over immediately.

The report writes (16) as c = (l² − m)/ω. Reading it directly from (15) gives the same thing: cω² = l² − m, so c = (l² − m)/ω². The report's (16) shows ω to the first power. This is a small discrepancy worth having noticed — see page 09.

5 · Homogeneous balancing gives N = 1

Balance the highest derivative u″ against the highest nonlinearity u³ in (14):

u ~ δN ⟹ u″ ~ δN+2, u³ ~ δ3N N + 2 = 3N ⟹ N = 1

So the ansatz (8) truncates after one term in each direction:

u(ξ) = A₀ + A₁/δ(ξ) + B₁ δ(ξ)
(17)

Three unknown constants — A₀, A₁, B₁ — plus ω still to be determined.

6 · The algebraic system

Substituting (17) and its derivatives with δ′ = δ² + χ into (14), then setting the coefficient of each power of δ to zero, gives the system the report labels (18):

l²B₁ − ω²B₁ + B₁³ = 0 3A₀B₁² = 0 B₁χl² − B₁χω² + 3A₀²B₁ + 3A₁B₁² + ( m − ½l² − ½·l⁴/ω² + l²m/ω² − ½·m²/ω² ) B₁ = 0 A₀³ + 6A₀A₁B₁ + ( m − ½l² − ½·l⁴/ω² + l²m/ω² − ½·m²/ω² ) A₀ = 0 A₁χl² − A₁χω² + 3A₀²A₁ + 3A₁²B₁ + ( m − ½l² − ½·l⁴/ω² + l²m/ω² − ½·m²/ω² ) A₁ = 0 3A₀A₁² = 0 χ²l²A₁ − χ²ω²A₁ + A₁³ = 0
(18)

Read the easy equations first — this is how you show you understand it

3A₀B₁² = 0 and 3A₀A₁² = 0 are the cheapest equations in the system. Either A₀ = 0, or both B₁ and A₁ are zero, which would leave nothing. So A₀ = 0 immediately. The bracketed group repeated through the system is just ζ written out. Being able to walk an examiner through the system in this order — cheapest equation first — is far more convincing than "Maple gave me the answer".

7 · The constants

Maple's solution to (18), as reported:

ω = ½ √( χ( 2χl² − l² + 2m + √Δ ) / χ ) A₀ = 0 A₁ = 0 B₁ = √( −¼ ( 2χl² + l² − √Δ − 2m ) / χ ) where Δ = 4χ²l⁴ − 12χl⁴ + 8χl²m + l⁴ − 8χm² − 4l²m + 16l²mχ + 4m²

Two things to notice, because they will be noticed

A₁ = 0. The negative-power half of the ansatz — the part that makes the method "unified" rather than an ordinary tanh expansion — contributes nothing for this equation. Honest phrasing: the general ansatz was used, and for this equation it collapsed to the positive-power branch.

The χ in ω cancels. χ(…)/χ is just (…). Written this way it looks like χ matters more than it does; in ω it does still enter through the 2χl² term and through Δ.

With A₀ = A₁ = 0, the solution (17) reduces to u(ξ) = B₁δ(ξ) — a single term. Everything downstream is B₁ multiplying the auxiliary function.

8 · The two solution families

Substituting the constants and the two branches of δ, with χ = ∓5 in the reported figures:

χ < 0 — hyperbolic

Uτ(x,y,t) = ½ · √( −(9/5)l² − (1/5)√(161l⁴ − 124l²m + 44m²) − (2/5)m ) × [ √(5P² + 5S²) − S√5 · cosh(2√5(ξ+R)) ] / [ P + S·sinh(2√5(ξ+R)) ]
(19)

χ > 0 — trigonometric

Uυ(x,y,t) = ½ · √( −(11/5)l² + (1/5)√(41l⁴ + 116l²m − 36m²) + (2/5)m ) × [ √(−5P² + 5S²) − S√5 · cos(2√5(ξ+R)) ] / [ P + S·sin(2√5(ξ+R)) ]
(20)

Check that these really are the general formulas at χ = ∓5

They are, and verifying it is a good use of ten minutes. Put χ = −5 into Δ: 4(25)l⁴ + 60l⁴ + l⁴ = 161l⁴; −40l²m − 4l²m − 80l²m = −124l²m; 40m² + 4m² = 44m². That is exactly the radicand in (19). The same substitution with χ = +5 gives 41l⁴ + 116l²m − 36m², the radicand in (20). And 2√−χ = 2√5 supplies the argument of cosh and sinh. The general constants and the reported special cases agree.

Three things about (19) and (20) that you should say before they are asked

The eiφ is missing. Equation (2) says U = eiφu(ξ), but (19) and (20) as printed give only the u part. The phase factor has been dropped. For plots of |U| this is harmless if φ is real; it is what makes the figures reproducible from the printed formula, which they are.

The square roots are of negative numbers. At θ = 60°, l = 0.5 and m = 0.866, the radicand in (19) evaluates to about −1.60. So B₁ is imaginary — about 0.633i. Likewise √(−5P² + 5S²) with P = 3, S = 2 is √(−25) = 5i. The solutions are genuinely complex-valued, and the figures plot |U|. This is not an error; it is a fact about the solution that you should state rather than be caught by. The lab on page 11 does the arithmetic in complex form for exactly this reason.

(19) is bounded on the real line — the obvious singularity is removable. Its denominator P + S·sinh(2√5(ξ+R)) does vanish where sinh = −P/S = −1.5, but the numerator vanishes at exactly the same point, because cosh² − sinh² = 1 forces cosh = √(P²+S²)/S and sinh = −P/S to occur together for every P and S. The limit is finite, |δ| ≤ √−χ, and |U| ≤ |B₁|√5 = 1.415 at θ = 60° — which is precisely the plateau in Figures 5 and 10. Genuine poles exist only at complex arguments, reached where x < −1/√β and ξ turns complex; that is the origin of Figure 1's spikes. This matters because "singular soliton" is the natural guess and it is wrong.
