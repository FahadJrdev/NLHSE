The project in one paragraph

You took the (2+1)-dimensional nonlinear hyperbolic Schrödinger equation — a model for how an optical signal spreads in single-mode fibre — replaced its integer-order derivatives with beta fractional derivatives, and solved it exactly using the Unified Technique. A traveling-wave ansatz collapses the PDE in three variables to a single ODE in ξ; separating real and imaginary parts fixes the wave speed; homogeneous balancing fixes the solution's size at N = 1; and solving the resulting algebraic system in Maple yields two closed-form families — a hyperbolic one for χ < 0 and a trigonometric one for χ > 0. Eleven Maple figures then show how obliqueness θ, the fractional order β and time reshape the wave.

How to use this site

  1. Rebuild the report in your own words

    Pages 01–06 walk the whole document: what the equation is, what the beta derivative buys you, how the Unified Technique works, the derivation line by line, and what each of the eleven figures actually shows. Read these once end to end.

  2. Answer out loud, not in your head

    The Q&A pages (07–09) each have a Quiz mode button. Turn it on and the answers hide; click a question to reveal. Every answer starts with a bold one-sentence version — that is the bit you say. The paragraphs under it are for when they push further.

  3. Run the mathematics

    Page 11 is a real Python environment in the browser — no install, no server. Every solution formula in the report is implemented there, and every code cell is editable. Change θ, change β, change χ, press Run, and watch the figure change. Being able to say "I reproduced Figure 1 numerically" is worth more than any amount of description.

  4. Read the hard questions before someone asks them

    Page 09 collects the things in the report that will not survive a determined examiner: an error in the printed ω that you can now derive and correct yourself, the Γ(β) / √β inconsistency, the missing eiφ factor in the final solutions, the unstated y in the plots, and the real reason the χ < 0 branch spikes. You lose nothing by knowing these. You lose a lot by being surprised by them.

Where you actually stand

This is an analytical project: exact solutions by symbolic manipulation, verified graphically in Maple. It is not a numerical-methods project — you did not discretise anything, and there is no error analysis or convergence study in the report. Most funded positions in this area are numerical. Say the sentence honestly and early, then show that the gap is small and you are already crossing it — which is what page 11 is for.
