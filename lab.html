1 · The constants, and one correction

This cell implements Eqs. (10)–(12) and (18)–(20) directly. Two things are worth knowing before you read it.

Everything is complex. At θ = 60° the radicand of B₁ is negative, so B₁ ≈ 0.633i. So is √(−5P² + 5S²) with P = 3, S = 2. And (x + 1/√β)β is a fractional power of a possibly negative number. Every square root here uses np.emath.sqrt, which returns a complex result instead of nan, and the plots show np.abs(U). This is not a workaround — it is what the solutions actually are.

The fix_omega flag. The report prints ω = ½√(χ(…)/χ), in which the χ cancels. Set fix_omega=False to use it exactly as printed; leave it True for ω = ½√((…)/χ). Cell 2 shows why that matters.

Read this result carefully — it is the strongest card you hold

        

          With ω as printed the relative residual is about 0.76 for χ = −5 and
          81 for χ = +5 — the solution does not satisfy the equation at all. With ω
          corrected it drops to ~10−6, which is exactly the
          truncation error of the central difference. Meanwhile δ satisfies its own ODE to
          10−8 either way, so Eqs. (10) and (11) are fine.
        

        

          The conclusion is precise and limited: B₁ is correct, and the printed ω is
          too large by a factor of √χ. The radical in the report reads
          √(χ(…)/χ), where it should read √((…)/χ) — one χ too many survived into the
          numerator. Everything amplitude-related in the figures reproduces exactly, which
          independently confirms B₁; what value of ω the original Maple worksheet used cannot be
          determined from the report, because the plots also depend on y, which is never stated.
          See page 09 for how to say this out loud.

7 · Is the χ < 0 branch actually singular?

      

        The natural assumption is that Eq. (19) blows up where its denominator
        P + S·sinh(2√−χ(ξ+R)) vanishes. This cell tests that assumption, and it fails: the
        numerator vanishes at the same point, so the singularity is removable and the solution
        is bounded on the real line by |B₁|√−χ — which is exactly the plateau in Figures 5
        and 10.

So where do Figure 1's spikes come from?

        

          From the transformation, not the solution. sinh(a) = −P/S also has roots with
          Im(a) = π, and there the numerator is not zero — those are genuine poles. They
          are reachable only when ξ is complex, which happens when
          x < −1/√β ≈ −1.12, because (x + 1/√β)β is then a fractional power of a
          negative number. Every figure that shows spikes plots x far below that threshold.
